### Q1. Écart entre API et application

- **Ce qui existe**
  - (2) **Google, réponse à l'audit Proof News / AI Democracy Projects (fév. 2024)** : Google a répondu que l'étude avait testé la version développeur de Gemini (API), qui « n'a pas les mêmes restrictions liées aux élections » que l'application grand public. ### Q7. Sur quoi les audits ont-ils été attaqués, et lesquels ont pesé avec une méthode légère ?

- **Critiques documentées et ce qu'elles ont changé**
  - **« L'API n'est pas le produit »** : Google (Proof News, 2024-02 : version développeur sans restrictions électorales ; AlgorithmWatch/CASM, 2024-08 : « les réponses de l'API ne peuvent être reproduites dans l'application ou le navigateur », tests internes montrant le blocage prévu) ; Meta (2024-02 : « meaningless », « Llama 2 is a model for developers ») ; OpenAI (2026-10 : « This study tested a developer API ») ; Anthropic (2026-11 : « some of Claude's key safeguards may not have been active »). Effets observables : Proof News a inscrit la limite dans son article ; AI Forensics a fait de l'écart web/API un résultat (Gemini 98 % de modération web, « not implemented on the API version ») ; IFPG a opposé une comparaison interne « comparable » ; EBU (2025) et ISD (2026) ont choisi explicitement les versions gratuites grand public « to replicate the default (and likely most common) experience » (EBU, p. 62) ; Liberties (2026) a testé les versions gratuites web (Chrome, VPN hongrois, sessions propres). Sources : Q1, Q4.
  - **« Usage non représentatif / requêtes rares »** : OpenAI (NPR, 2026-11 : « not representative of how most voters use ChatGPT ») ; Microsoft (NPR/NewsGuard, 2026-08 : les requêtes testées sont « rares » et non représentatives) ; Anthropic (0,01 % des conversations). https://www.npr.org/2026/08/30/nx-s1-5876436/chatbots-search-propaganda (consulté le 2026-11-10).
  - **« Échantillon trop petit / instantané »** : reconnu par les auditeurs eux-mêmes : Proof News (130 réponses, « not necessarily representative ») ; Liberties (200 observations = 5 profils × 10 répétitions × 2 modèles × 2 conditions, « indicative rather than definitive ») ; NewsGuard (FAQ : « Attempting to replicate our audit weeks or months later will likely produce different outputs ») ; DRI (« responses cannot be exactly reproduced »). https://www.newsguardtech.com/?p=31144 (consulté le 2026-11-10).
  - **« Jugement contesté »** : Google et DuckDuckGo ont contesté la méthodologie du test NPR/NewsGuard (août 2026) en soutenant que des réponses classées « échec » donnaient du contexte et des liens utiles ; NPR a maintenu ses résultats (chatbots : ~trois quarts de démentis sur 15 récits faux, déc. 2025–juil. 2026). Même source. Mitigation adoptée par EBU : assistants anonymisés pour les 271 journalistes évaluateurs (PDF p. 63).
